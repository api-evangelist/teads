# Teads

> Teads is an omnichannel advertising technology platform (combined with Outbrain since 2024) reaching audiences across video, display, CTV, and conversational surfaces on 10,000+ premium publisher properties in 50+ markets. For developers and advertisers, Teads exposes server-side and contextual REST APIs plus first-party mobile ad SDKs.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Teads developer portal and public documentation on 2026-07-21. Teads does not publish an official /llms.txt.

## APIs

- [Teads Conversions API](https://developers.teads.com/): server-side conversion event delivery (Purchase, AddToCart, Lead, ViewContent, InitiateCheckout, etc.) to base URL https://ca.teads.tv (v1), authenticated with a Conversion API Token generated in Teads Ad Manager. Uses first-party cookies tfpai/tfpvi/tfpsi and event id auctid.
- [Teads In-Chat API (V2.0)](https://developers.teads.com/docs/Chatbot-AI-SDK/Getting-Started/integration-guide/): POST https://mv.outbrain.com/Multivac/api/in-chat-recs — retrieves contextual ad recommendations for chatbots/LLMs, authenticated with a Partner API Key (`key` param); requires User-Agent and X-Forwarded-For headers.

## SDKs

- [TeadsSDK-iOS](https://github.com/teads/TeadsSDK-iOS): CocoaPods `TeadsSDK` and Swift Package Manager.
- [TeadsSDK-android](https://github.com/teads/TeadsSDK-android): Maven `tv.teads.sdk:sdk` from the Teads Artifactory repo.
- [TeadsSDK-ReactNative](https://github.com/teads/TeadsSDK-ReactNative): React Native >= 0.78.0 (Fabric).
- [TeadsSDK-flutter](https://github.com/teads/TeadsSDK-flutter): Flutter/Dart.
