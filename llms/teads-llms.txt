# Teads

> Teads is an omnichannel advertising technology platform — the combined Outbrain + Teads company, operating under the Teads brand — reaching audiences across video, display, CTV, native, feed and conversational surfaces on premium publisher properties in 50+ markets. For developers, Teads exposes two REST APIs (In-Chat Recommendations and Conversions) plus first-party mobile ad SDKs for iOS, Android, React Native and Flutter.

Generated by the API Evangelist enrichment pipeline from the Teads developer portal and public documentation on 2026-08-13. Teads does not publish an official /llms.txt (probed: developers.teads.com/llms.txt 404, ca.teads.tv/llms.txt 404, mv.outbrain.com/llms.txt 404, www.teads.com/llms.txt 406). Teads publishes no OpenAPI, AsyncAPI or GraphQL contract; everything below is documented in prose only.

## APIs

- [Teads In-Chat Recommendations API (V2.0)](https://developers.teads.com/docs/Chatbot-AI-SDK/Getting-Started/integration-guide/): `POST https://mv.outbrain.com/Multivac/api/in-chat-recs`. Returns contextual sponsored and organic ad recommendations for chatbots and LLM surfaces. Authenticated with a Partner API Key in the `key` QUERY parameter. Query params: `key`, `widgetJSId`, `response_version` (must be `2.0`), `response_types` (`catOrKeywords`, `embeddings`, `BrandDisplay`), one of `contentUrl` / `bundleUrl` / `portalUrl`, `lang` (required with bundleUrl/portalUrl), `bf` (CPM bid floor), `cors`, `testMode`, `api_consent`, `cnsntv2` (IAB TCF v2.0 string, required in the EU). JSON body: `keywords`, `iabCategories` (IAB V1), `chat`. Mandatory headers: `User-Agent` and `X-Forwarded-For` carrying the END USER's agent and IP, plus `Content-Type: application/json`.
- [Teads Conversions API](https://developers.teads.com/): server-side conversion event delivery (Purchase, AddToCart, Lead, ViewContent, InitiateCheckout) to `https://ca.teads.tv` (v1), authenticated with a Conversion API Token generated in Teads Ad Manager. Correlates with browser activity via the first-party cookies `tfpai` (carries `auctid`), `tfpvi` and `tfpsi`. Liveness: `GET https://ca.teads.tv/health` returns `server is up`.

## Calling the In-Chat API correctly

- The response is keyed by engine type under `results`. Each group has `documents[]` and a `tracking` object; each document carries `pos`, `adType`, `url`, `thumbnail_url`, `source_display_name`, `content`, `target_domain`, `cta`, `cpm`/`net_cpc` and `doc_tracking`.
- Three tracking signals are MANDATORY and are the caller's responsibility: fire `results.{type}.tracking.reportServed` with `&pos=X-Y` appended when the widget initializes; fire every URL in `doc_tracking.pixels` when the creative renders; fire every URL in `doc_tracking.on-viewed` ONLY when the ad enters the visible viewport. Missing the viewability signal zeroes revenue on vCPM campaigns without producing an error.
- Requesting `BrandDisplay` adds a `results.display` object with `html`, `div_id`, `placement_id`, `width`, `height`, `outiframe_allowed` and `om`.
- The number of recommendations returned is fixed by the `widgetJSId`; there is no limit, cursor or page parameter.
- Do not put PII (emails, names, phone numbers) in `chat` or `keywords`.

## Known gaps (do not assume these exist)

- No OpenAPI/Swagger document on any host. No GraphQL. No AsyncAPI. No webhooks.
- No published rate limit, quota, throttling policy, 429 documentation or rate-limit response header anywhere in the 93-page developer portal.
- No error catalogue, status-code table or RFC 9457 problem+json envelope for either REST API.
- No idempotency key or replay-safe processing guarantee, including on the Conversions API.
- No OAuth 2.0, OIDC, scopes, token expiry or documented key rotation.
- No status page (`teads.statuspage.io` resolves to Atlassian's marketing site, not a Teads page).
- No public pricing; access is issued by a Teads account representative.

## SDKs

- [TeadsSDK-iOS](https://github.com/teads/TeadsSDK-iOS): CocoaPods `pod 'TeadsSDK'` and Swift Package Manager. Latest 6.2.0 (2026-06-23).
- [TeadsSDK-android](https://github.com/teads/TeadsSDK-android): Maven `tv.teads.sdk:sdk` from the Teads JFrog Artifactory repo (not Maven Central). Latest 6.2.1 (2026-08-05).
- [teads-react-native](https://www.npmjs.com/package/teads-react-native): npm, 6.2.0 (2026-06-22). Requires React Native >= 0.78.0 with the New Architecture (Fabric).
- [teads_sdk_flutter](https://pub.dev/packages/teads_sdk_flutter): pub.dev, 1.0.5 — last published 2022-12-16 and three major versions behind the native SDKs.
- SDK 6.0.0+ exposes a unified placement interface via `Teads.createPlacement()`: Media (video), Media Native, Banner, Interstitial, Feed and Recommendations placements, with `TeadsAdPlacementEventsListener` for all types.
